# HireMind AI

AI-powered job intelligence and interview preparation platform.

## Vision

HireMind AI helps a candidate understand how well their resume matches a job, identify skill gaps, prepare for role-specific interviews, practice through an adaptive mock interview, and receive an actionable performance report.

## Core workflow

1. Upload a resume.
2. Add a job description.
3. Extract structured resume and job information.
4. Analyze skills and requirements.
5. Calculate an explainable match score.
6. Identify skill gaps.
7. Generate personalized interview preparation.
8. Run an adaptive mock interview.
9. Evaluate the interview and show a performance report.

## Planned stack

- Frontend: Next.js, React, TypeScript, Tailwind CSS
- Backend: Python, FastAPI
- Database: PostgreSQL
- Vector search: pgvector
- ML/NLP: scikit-learn, spaCy/transformers, sentence-transformers where appropriate
- LLM integration: provider-agnostic API layer
- Deployment: Vercel + Render
- Source control: GitHub

## Development principle

HireMind is designed as an understandable, testable, production-style AI/DS portfolio project. AI-generated code will be reviewed and explained rather than blindly accepted.
